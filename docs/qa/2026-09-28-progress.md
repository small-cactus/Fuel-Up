# Fuel Up QA — September 28, 2026

This checkpoint fixes the reported Home/onboarding layout and camera defects and several additional visual problems. It is **not a clean bill of health for every subsystem**. The unresolved gates below remain failures.

## Changes

- Compact reset pill with a 44-point touch target and balanced spacing between the cards and native tabs. Camera padding uses measured card height.
- Native MapKit camera targets change on meaningful GPS/station updates. Removed the twice-per-second refit timer, extrapolated display GPS, and delayed unanimated refit.
- Removed the selected chip border and the shrink-to-nearly-zero workaround. Hidden annotations remove their glass and text together. Removed another unused-state timer that rerendered Home after every pan.
- Atomic onboarding grade/radius persistence, serialized preferences, foreground permission refresh and transient GPS handling. Radius preview uses permitted GPS; all five native picker choices are persisted, including E85.
- Reliable Continue labels; permission pages scroll so content cannot be trapped behind the footer on compact phones. Corrected location/privacy and search-distance copy.
- Launch blur is scoped to Home, so a direct link to another screen cannot stay covered while waiting for a map that never mounts.
- Price sheets use native content-sized detents, show an explicit empty state, and wire Go to the selected navigation app. Card headings reserve space for Go.
- Current-only Trends data shows its average without an empty historical chart. The leaderboard retains the regular layout and stacks at large text sizes. Designer navigation follows dark mode and its compact SwiftUI preview has explicit host dimensions so savings remain visible.
- Split onboarding pages, Home camera/location/geometry/probe code, and the Trends leaderboard into focused modules; removed two unused presentation implementations. Home still has a substantial controller and is not fully decomposed.
- GasBuddy is the only live provider. Corrected Diesel filter to 4; E85 uses 5 and never inherits another grade's price. Supabase `gas-prices` and `fuel-repair` were deployed in the preceding checkpoint.

## Unresolved gates and limits

- The live cluster integration probe timed out. The existing production constant `ENABLE_CLUSTER_MERGE_TRANSITIONS=false` produces single-station annotations, so the split/merge probe cannot acquire a multi-station cluster. The quality threshold remains 2 px; no assertion was removed or weakened. The runner now accepts `FUELUP_SIMULATOR_UDID` to target one simulator when several are booted.
- The current predictive/cohort rerun passed **31/34** tests. Failures: production robustness thresholds (including false positives, wrong stations, recall and calibration); rich-history accuracy **96% vs required 97%**; missing classified no-corridor failures in the trace breakdown. None was redefined as passing.
- Argent native profiling failed to produce its `.trace` file on Xcode 27. CPU/hang/leak exports and the combined profile were unavailable. Native animation smoothness is not quantitatively certified.
- Full ML benchmark rerun, all permission combinations, all accessibility settings and complete physical-device behavior remain unverified.
