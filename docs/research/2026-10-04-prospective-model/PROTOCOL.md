# Prospective nationwide model development

Frozen before fitting this experiment. Research only; no production price or ranking changes.

Use all successful immutable batches available through the fixed export cutoff, including partial hours with explicit missingness. Verify SHA-256, exact catalog IDs, collection times and region before use. Never fetch the provider from this pipeline. Source quotes are observations, not verified pump truth.

Preserve the September 30 market-lag protocol: features and targets observed before October 3 18:19 UTC may train; observations after that boundary and before October 5 18:19 UTC are development validation. October 5 18:19 through October 7 18:19 is inaccessible final evaluation until settings are frozen. Purge training targets crossing the boundary. No station-ID feature; repeat stations across chronological splits are disclosed.

Primary supervised task: predict the next independently newer report for the same station, grade and payment, observed within 24 hours. Require its source time to advance at least five minutes; do not call absent outcomes unchanged. Retain unchanged-price newer reports as negative controls. Build source-report events at earliest observed availability, not backdated source time. Inputs include causal station price/movement history, report ages, missingness, and lagged same-state/grade/payment market statistics. Peer features use only completed previous hourly snapshots. Geographic peer precision is limited to available metadata and is reported.

Compare unchanged price, causal peer/market movement and current rules where the exact required inputs are available; do not label a substitute the production baseline. Fit substantial CatBoost regression models under squared, absolute and tail-aware objectives and a residual temporal network at two capacities if compute permits. Evaluate ensembles only on development validation. Preserve model checkpoints, all settings, data hashes, feature definitions, predictions and runtime environment. Use early stopping and report actual trained iterations/epochs and parameter count.

Report MAE/RMSE, 5/10-cent accuracy, changed-report error, worst-5% error, severe under/overestimation, and ranking-regret diagnostics with coverage. Select on balanced mean/tail evidence without hiding ordinary-quote or genuine-discount regressions. Repeated grades/payments/reports are dependent; use station-grouped comparisons. Report intervals as empirical forecast uncertainty, never guaranteed pump-price bounds. Nationwide state-level ranking is not a valid local candidate set; location-based ranking requires city panel evaluation.

Choose a useful model based on evidence, not parameter count. No deployment is authorized by a development improvement. Final evaluation is not yet available and must remain untouched.

User-directed fallback order: if trained candidates do not improve meaningfully, evaluate Google's TimesFM 3 against the same chronological data. If that also fails, investigate lagged crude-oil prices using historical oil and retail series long enough to identify 1–60 day relationships; test incremental out-of-time value before adding any oil feature. A few days of station observations cannot identify a 30-day pass-through lag. Features must respect publication availability, not merely observation dates. TimesFM 3 model license and deployment suitability are separate from research evaluation.

Training export cutoff: 2026-10-04 02:30 UTC; only runs whose original deadlines precede the cutoff are included. Static coordinates are read from the existing station catalog for six-mile neighborhood features; prices and names from the latest serving cache are never model inputs. Peer summaries use previous-hour observations only. Research recommendation panels include all priced stations within six miles of each of the 24 city origins, separately by fuel/payment. Membership/preferences/distance tradeoffs and simultaneous pump truth remain outside this proxy.
